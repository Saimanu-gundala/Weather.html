# Weather App

Built by [Sai Manu Gundala]

A simple web app that shows the current weather for any city.

**Live demo:** https://saimanu-gundala.github.io/weather-app

## Features
- Search any city in the world
- Shows temperature, humidity and wind speed
- Handles "city not found" and network errors

## Tech
HTML, CSS, JavaScript, Open-Meteo API (free, no API key)

## How to run
Open `index.html` in any browser.
